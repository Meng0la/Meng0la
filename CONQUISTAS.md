# Conquistas no GitHub

As conquistas reconhecem atividades no GitHub e podem aparecer no perfil quando a exibição estiver habilitada.

- **Quickdraw:** fechar uma issue ou pull request logo após a abertura.
- **Pull Shark:** ter pull requests integrados.
- **YOLO:** integrar um pull request sem revisão prévia.
- **Pair Extraordinaire:** colaborar como coautor em um pull request integrado.
- **Galaxy Brain:** ter respostas aceitas em discussões elegíveis de projetos que utilizam GitHub Discussions.
- **Starstruck:** um repositório atingir a quantidade necessária de estrelas.

A concessão e o tempo de exibição dependem do GitHub. Consulte as [configurações de visibilidade](https://docs.github.com/pt/account-and-profile/how-tos/contribution-settings/manage-visibility-settings-for-private-contributions-and-achievements) para controlar o que aparece no perfil.
